## 维护性检查

renderer 按任务、设置、收入、请假、打卡拆分；通用输入、弹窗、草稿与格式逻辑复用。main 统一持久化/修订号/事实/时钟，preload 仅暴露白名单接口。纯业务算法保留已验证的 JavaScript 并通过类型适配调用，新桌面与 React 层使用 TypeScript；没有以全面改写算法代替兼容验证。补录校验为 UI/main 共享模块；样式使用独立 check-field/app-toast 避免继承旧任务类。

main 与上游同步检查无新增提交、无分叉，保留原先未提交的业务与同步脚本改动。没有提交本地测试目录、个人数据、构建包、证书或凭据。

## 明确边界与遗留

1. Windows 配置保留，本轮按用户决定不构建/安装/运行验收；Intel Mac 仅构建与签名/镜像校验，未在 Intel 机器实跑。
2. Mac 当前为本地 ad-hoc 签名，未做 Developer ID、公证或正式签名自动更新；默认手动下载。未创建公开 Release、标签或改动旧 appcast。
3. 运行时依赖审计无漏洞、高/严重项为 0；Forge 开发工具依赖仍有 17 个 moderate 依赖节点，归于 glob 与 minimatch 两类公告（GHSA-3g3m-2fjr-6pw4、GHSA-g3hv-75wg-m249）。未做强制跨主版本升级，构建输入受项目控制；此项保留待工具链上游修复。
4. 税务参数是带适用期的政策快照，调休依赖公开数据源；无可用中国日历时显示失败，不静默换口径。当前设置按整月重算，尚无历史薪资/排班版本。
