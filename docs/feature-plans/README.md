## 维护约定

- 一个功能一个文件，沿用稳定 ID；变更更新版本和确认状态。
- 区分用户明确要求与建议规则；实现存在、技术验证和用户验收分别记录。
- 下班小票归属下班成功反馈；其他趣味卡片按需开启，小游戏统一从游乐场进入（入口为建议）。
- F01 已归档至已实现方案，验收边界见记录；G01–G07 已逐项展开玩法、计分、操作、动效、恢复和验收，仍为候选计划。
- 开发前重新核对工作区、提交具体交互/技术方案和彩色流程图，取得明确批准。
- 方案实施后归档到 `implemented/`，同步更新索引与相对链接；归档与用户验收分别记录。
