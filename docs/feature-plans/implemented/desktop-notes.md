## 入口及范围

任务卡片和各尺寸任务清单可贴出单项；完整清单及主界面的“桌面便签”可组合、命名、调整顺序、增减成员。管理可隐藏、显示、移除便签、切换晾衣线、找回位置。任务只存一份，单项重复贴出幂等，多张清单可引用同一任务。成员删除后保留空清单；删除原任务会同步清理引用。

首次没有便签时不显示线，首次贴出或新建清单时显示。窗体仍是独立透明窗口，尺寸在折叠/拖动全过程保持不变。纸张背景缩放、文本独立过渡，透明空白区域按可见纸面和夹子门控穿透。晾衣线隐藏时收起挂着的便签，桌面便签仍显示。跨 Space、全屏覆盖和主屏外多屏视觉由用户验收，不声称已经测试。

## 数据、接口与职责

- `src/shared/desktop-notes.ts`：业务模型与任务投影。
- `src/migration/desktop-notes.js`：便签结构校验，与备份/导入共用；`desktop-notes-store.ts` 负责带修订检查的业务修改和删除引用清理。
- `src/shared/desktop-note-window.ts`：窗口几何、受限通信契约；`desktop-notes-controller.ts` 负责原生窗口注册、来源鉴权、就绪握手、原位取放、屏幕变化及资源释放。
- `desktop-notes-preferences.ts`：本机坐标、挂起/展开状态，排队原子写入，损坏保护及显式重置备份。
- `src/main/main.ts`：将受限便签任务操作接入原任务命令队列，保留 requestId、expectedRevision、完成奖励及统一落盘结果。窗口加载不占业务队列。导入重新装载模型，退出同时保存位置并释放便签窗口。
- `src/preload/desktop-notes.cts`：仅本页面通信；桌面窗口只收到自己的任务投影，没有收入、考勤或其他便签内容。
- `src/renderer/desktop-notes.tsx` 与 `features/desktop-notes`：正式和样机共用 UI、纸张样式及管理面板。样机仅切换依赖与模拟数据，避免长期维护两套手感。

便签元数据保存在 `dogcow.desktop-notes.v1`，属于统一 Repository 及迁移白名单；坐标不纳入便携业务备份。编辑使用便签修订号；任务命令使用任务修订号和重复请求收据。状态“已应用、未落盘”保留权威内存态，重试落盘不再次执行任务操作。

## 异常与恢复

| 情况 | 处理 |
| --- | --- |
| 原任务已删除 / 修订冲突 | 使用最新投影，拒绝过期写入，不自动反转任务状态 |
| 页面加载、握手或渲染失败 | 清理失败窗口，记录问题编号，管理中重新显示后重试；业务队列继续可用 |
| 未保存 | 原位提示，管理与便签提供保存重试，退出沿用统一保存保护 |
| 便签数据损坏 | 锁定编辑并保留原始数据，不用空对象覆盖；通过已有数据恢复入口处理 |
| 坐标损坏 | 默认位置可继续查看，禁止自动覆盖坏源；明确重置时先备份 |
| 拖动取消 / 捕获丢失 | 恢复起点，成员数据不变 |
| 拔屏 / 屏幕缩放 | 桌面坐标夹回工作区，挂起位置按原横向比例恢复 |

- 管理组件用 navigate/applyDestination 统一内部及外部跳转入口。草稿未保存或命令执行中，保存最新目标并保留编辑；保存成功或明确放弃后再跳转。保存失败、重试期间继续输入均不会提前切换，关闭管理页时清理待跳转目标。
- 控制器通过 wantedRoles 复用 updateNotes 的单一可见性规则，窗口创建前及异步加载后重新核对需求。已不需要的窗口按正常取消处理，加载完成或失败均不生成持久窗口错误；显示前核对窗口归属，旧窗口的崩溃事件不会销毁替代窗口。
- failures Map 按窗口保留问题编号和显式重试状态，替代分散的 failed Set 与全局可写 windowError。总提示从记录派生；重试开始时保留错误，成功只清除对应窗口；其他失败继续提示。显式隐藏或删除后，不再显示该窗口的恢复提示。
- publish 每次使用同一个业务快照生成各窗口投影，保持版本、待保存状态和错误信息一致，避免重复读取投影。
