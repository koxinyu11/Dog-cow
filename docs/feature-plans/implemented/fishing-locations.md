# F01 两处新钓场与落点、水层

方案 v1 已确认并实现；技术检查通过，视觉及实际体验待用户验收。

- 午后池塘、芦苇河湾沿用原规则。
- 荷风浅荡：发现 10 种鱼解锁，荷叶边 / 草隙 / 亮水面。
- 旧桥深潭：发现 20 种鱼解锁，桥影 / 回水湾 / 倒木旁。
- 新地图提供浅钓 / 沉底，地图内点击落点；入口为商店的「钓点与鱼饵」。
- 新地图分别复用池塘与河湾图鉴。共享地图配置位于 `src/shared/fishing-maps.ts`；常规鱼群按落点偏好、水层和体型重新分配权重，类别总概率及固定神话遇见概率沿用现有规则。沉底更偏底栖或大型鱼；已有承重、磨损和护线扣规则继续生效。
- 后台负责校验解锁、落点和水层，沿用 `FISHING_RULE` 及现有 IPC 诊断和保存重试。抛竿后禁止修改条件，结果与落点随本竿保存；重载不重抽，重复收线按请求编号幂等处理。
- 旧存档无落点字段时原地图不新增字段；新地图缺少选择时使用首个落点浅钓。非法落点报错并保留原数据。含新地图的存档不应交给旧版本读取。
- 场景沿用现有时间调色、人物、鱼竿和收获呈现。新地图保留完整场景以避免宽窄窗口裁掉落点。后续地图与偏好在共享配置扩展，景物在 Backdrop / Water 维护。

验证：`npm run build`；`npm test`（663 项通过）；`git diff --check`。新增测试覆盖全部 12 种组合在不同鱼情与鱼饵下的概率归一、固定遇见概率、浅底体型差异、解锁、非法选择、存档、冻结结果及重复结算。没有自动执行批量 UI 验收。
