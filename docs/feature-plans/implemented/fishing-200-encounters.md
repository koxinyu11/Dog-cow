# F02 · 200 种鱼与道具搭配相遇

方案 v1 / v2 已获用户确认；本地实现，未提交、未发布。视觉及功能体验待用户验收。

## 内容和入口

- 鱼类由 72 扩至 200 种，连同原有生物和物品，共 250 条图鉴。新增 64 种常规鱼、32 种钓场/落点/水层限定鱼、20 种单鱼饵限定鱼、12 种鱼饵与挂件组合限定鱼。
- 商店 → 补给：6 种新鱼饵（莲香饵、发光虫饵、发酵谷饵、特制腥饵、青苔团、暖香丸）。每包 10 份，价格 10–14 狗牛币，发现 5/10/20 种鱼后购买。每竿一份，收线时结算；空钩或断竿也消耗。用完自动切回普通饵。
- 商店 → 挂件：月光铃、旧铜环、琉璃坠、芦苇结，45–75 狗牛币，永久拥有且一次佩戴一件。购买即佩戴，可取下，不占护线扣位置。
- 主场景鱼饵/挂件选择器复用后台校验。配对有特殊相遇资格时出现轻微场景回应，表示条件有反应，不预告本竿结果。
- 图鉴增加“尚未发现”“道具限定”筛选。未发现条目显示线索，钓到后可展开已验证搭配。原有图鉴、锁定鱼获、钱包、皮肤及鱼竿结果保留。

## 抽取规则

- 每条限定鱼的条件与稀有度分开定义。钓场限定只在精确钓场出现，不被新地图的旧栖息地复用自动带入。
- 单鱼饵限定每个符合条件的条目每竿 1.8% 或 2.5%；组合限定为 1.2%，少数珍稀组合为 0.6%。未满足条件时为零。首版不添加保底。
- 特殊条目在原鱼类总份额中预留绝对概率，其余份额按常规鱼群权重分配。不会增加空钩率，也不从原神话保留概率扣取。旧神话鱼按原鱼情规则保持每条每竿 0.01%–0.1%，不受新鱼饵、挂件额外加成。
- 未遇见限定鱼时保留普通鱼、生物、宝物等原有收获；原有承重、磨损、护线保护规则继续生效。只有成功收回才记录发现。
- 普通新鱼以较低权重加入原鱼池，保持原鱼仍可获得；探索饵继续偏向未发现的常规鱼，不能绕过限定条件。

## 保存和维护

- 复用 Fishing.execute 串行命令、Repository 快照、钱包和 requestId 幂等。抛竿时锁定挂件、落点、鱼饵预留与结果；有未收回鱼竿时禁止换装。
- 旧装备只对缺失的新库存、挂件字段补默认值；显式非法库存、未知/重复/未拥有挂件拒绝读取，保留原数据。旧鱼竿记录无需新增字段才能读取。
- 配置：`src/shared/fishing-catalog.ts`；条件：`fishing-encounters.ts`；装备：`fishing-gear.ts`；抽取/存档：`fishing.ts`；购买与结算：`src/main/fishing.ts`。新增鱼种沿现有模板插画扩展了 12 种轮廓，限定鱼有灯腹、伞鳍、铜钱鳞、骨节等辨识结构。
- 新存档包含新增鱼、饵和挂件后，不适合交给旧版本读取。升级前导出备份。

## v2 · 250 条图鉴

用户已确认新增 22 条非鱼收获，鱼类保持 200 种，总计水边生物 18、工位旧物 14、宝物 18。新增物品配置在 `src/shared/fishing-finds.ts`，插画在 `FindArt.tsx`，沿用已有图鉴线索、场景回应与抽取校验，没有新增装备类型。

- 生物：溪边蝾螈、龙虱、水黾、溪蟹、扁卷螺、淡水青虾、白鹭与萤火虫。后两者只记图鉴，不入鱼篓、不计鱼类总数。
- 旧物：缠线耳机、失灵鼠标、半截铅笔、褪色车票、空订书机、打卡机残片。
- 宝物：莲露珠、琥珀虫珀、桥底铜铃、月纹瓷片、苇编小舟、封存的加薪信、星光八音盒、无刻度沙漏。
- 莲露珠：莲香饵＋琉璃坠，荷叶边浅钓；桥底铜铃：寻宝磁钩＋旧铜环，桥影沉底；苇编小舟：青苔团＋芦苇结，草隙浅钓。三者每竿符合条件时为 0.15%。
- 星光八音盒：寻宝磁钩＋月光铃，回水湾沉底，每竿符合条件时为 0.08%。四件宝物从原宝物类别份额中预留，不改变类别总份额及旧神话绝对概率；不满足搭配时不会遇见。
- 新条目仅作收藏与出售，复用已有快照、冻结与幂等结算，不改变鱼类解锁计数。
