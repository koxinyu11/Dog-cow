## 主要功能

早上打开狗牛，把今天要啃的活儿列好。做完一件，小牛就离草地近一点；忙累了，看看收入时钟和下班倒计时——今天的草料，心里有数。

以下为当前正式版的主要功能。

| | 狗牛能帮你 | 怎么用 |
| :---: | :--- | :--- |
| 📝 | **把活儿赶进围栏** | 待办写下来，轻重缓急排一排；周计划和月历帮你看清哪天啃哪件。 |
| 🐮 | **你干活，小牛吃草** | 推一推任务进度，小牛就往草地走；当天任务全完成，撒花收工。 |
| 💰 | **数数今天的草料** | 填好薪资和工作时间，看每秒收入、今日与本月累计，再瞄一眼离下班还有多久。 |
| ☕ | **歇口气，也记一笔** | 上班、午休、下班点一下；误触下班当天可撤回，忘打卡可以补，带薪、无薪请假也能记。 |
| 🪙 | **摸鱼攒点狗牛币** | 拉屎、抽烟、咖啡和自定义活动分类计时，按已记录金额兑换狗牛币，解锁动态壁纸。 |
| 🎨 | **自己的工位自己摆** | 想看任务就摆任务，想看收入就摆收入；模块顺序、标题随你改，也能收成小横条。 |
| 🍱 | **午饭不再纠结** | 从 568 道菜中挑选午餐，或开个盲盒；卡片随尺寸调整布局。 |
| 🧾 | **记下老板欠的账** | 查看打卡对应的加班时间，补记处理消息的时间，并导出欠条 PNG；加班费需在收入设置中开启，默认关闭。 |
| 💾 | **小本本留在自己手里** | 任务和设置自动保存在本机，换版本前还能导出备份，给辛苦记下的事留个底。 |

<sub>工资换算卡片支持调整换算项目。收入与税费为估算；“偷出金额”是工作时间的价值拆分，不是额外工资。首页默认展示九类卡片，可调整大小、拖动排列或移除。</sub>

## Mac 菜单栏状态面板

菜单栏默认显示狗牛剪影，也可在“设置 → 外观 → 菜单栏”切换为今日收入或下班倒计时。点击入口可查看工作状态、今日/本月收入估算、已工作时长、任务完成度、下一项任务和盼头倒数日；更多盼头可展开，管理操作复用主窗口编辑器。

面板与主窗口可同时显示。关闭主窗口后继续后台常驻，再次点击菜单栏入口或在面板内按 Esc 收起面板；需要结束应用时使用面板的退出图标或 Cmd+Q。显示选择本地保存，面板跟随明暗主题并支持减少动态效果。

此功能自 v3.0.12 起包含在正式版中；实现范围与验证记录见[菜单栏计划归档](docs/feature-plans/implemented/menu-bar-status.md)。

## 打工人隐藏壁纸

新增 9 张隐藏壁纸，获得对应称号后出现在“设置 → 外观 → 背景”，带 ✨ 的会动：带薪下钱雨 ✨、奶茶自由 ✨、无理小金库、到点跑路 ✨、周五永居 ✨、周一免疫、需求粉碎机 ✨、资本家克星、终身股东 ✨。解锁条件不公开，靠打工自己发现。新获得称号时，解锁提示会一起列出新壁纸；升级前已有的称号对应壁纸直接可用，不再提示。关闭动效或系统减少动态效果时显示静态画面。自 v3.0.15 起包含在正式安装包中。

## 最新版更新

当前正式版为 **v3.1.0**，提供 Apple Silicon 的 DMG、ZIP 和 SHA-256 校验文件。以下按已发布标签及对应提交整理；测试和维护版本单独注明，历史平台支持不代表当前安装包范围。

### [v3.1.0](https://github.com/koxinyu11/Dog-cow/releases/tag/v3.1.0) · 当前正式版

新增下班撤回、自定义带薪活动、狗牛币与动态壁纸、Mac 一键安装更新和自欺欺人显示模式；修复金额账本及保存恢复问题。

#### 账本与保存恢复修复

- 当前月份的欠款账本完整同步，删除最后一笔欠款或重算归零后，不再保留旧的可兑换金额；其他月份、已兑换狗牛币和已购项目保留。
- 钱包兑换与购买在本机保存成功后才反馈成功、自动应用壁纸；保存失败时提供重试，并暂停新的钱包操作。重试只保存原修改，不重复加币或扣币。
- 考勤确认窗口在无带薪活动的情况下，也可直接重试失败的保存。
- 安装恢复按目标和时间识别已被后续成功安装解决的旧失败，不再重复提示；新的失败和恢复材料继续保留。

#### 撤回下班

- 下班确认按钮明确为“确认下班”；当天已下班后，可从打卡卡片或收工小票撤回，重启后仍可操作。历史日期继续通过补录实际时间更正。
- 撤回仅清除当天的下班记录，保留上班、弹性排班和午休事实，重算收入、工时与欠款；误下班至撤回之间按工作或原有午休状态连续计算。原先下班补齐的当天收入会恢复实时口径，因此显示金额可能下降。
- 自动结束的带薪活动不自动恢复；已解锁职称与狗牛币余额保留，下班资格和金额账本按更正后的事实更新。旧收工小票失效，已导出的图片不自动修改。
- 本机保存失败时保留当前修改并提供重试保存；正式版号与下载链接不变。

#### 自欺欺人

- 设置 → 外观新增“自欺欺人”开关，默认关闭并在本机记住选择。开启后，主页收入、秒薪、偷出金额、带薪活动、老板欠款和背景绑定的收入指标显示为真实金额的 10 倍；关闭立即恢复。
- 只改变展示，不改变实际计薪、记录、工资输入、历史明细和导出；工时、进度、商品单价及换算结果保持真实口径。

#### Mac 一键安装更新

- 新增应用内“安装并重启”和 DMG 内“安装或替换狗牛.command”入口，复用下载来源与 SHA-256 校验；安装前保存并备份数据，替换失败恢复旧应用，新版未确认启动时保留恢复材料。
- 保存失败、目标应用仍在运行、目录不可写或安装包不匹配时停止安装。仅支持 Mac，Windows 保留手动安装；Developer ID 签名与 Apple 公证尚未接入，不保证免除系统安全提示，不清除下载隔离标记。
- 安装替换已通过临时目录内的隔离打包应用验证；未对用户正式安装执行更新。详见[安装更新技术说明](docs/update-install.md)。

#### 带薪活动分类

- 主屏原“带薪拉屎”模块标题可切换“带薪拉屎 / 抽烟 / 买咖啡 / 带薪自定义”，各有图标、场景和操作反馈；切换不会停止正在进行的计时。
- 默认标题不再在 Tab 旁重复显示，编辑按钮仍保留；自定义标题与绑定的实时数据保留。小、中、大、长、竖分别使用紧凑计时（状态与自定义名称合为一行）、图标徽章三列、场景统计、横向和纵向布局，标题控制与 Tab 分行，不使用整体缩放。长、大、竖卡片的主按钮带动作文字（如“开始蹲班 / 拉完了”）。
- 动效统一：空闲时静止；开始时播放一次入场动画，计时中只有低频轻动；结束且确有新增偷出时间时，显示“+时长 · 金额 计入合计”并飘一次金币，取消或无增量时直接复位。窗口隐藏或卡片不在视野内时暂停装饰动画；开启“减少动态效果”时只显示静态状态。
- 四类可同时计时，同类最多一条未完成记录。分类分别展示有效时间价值，活动合计对重叠时间去重，沿用工作时间、打卡、午休和请假口径，不增加工资、不扣实际工时。
- “带薪自定义”提供一个活动位，可设置 1～12 个字符的名称并从可搜索的 16 项图标库中选择图标，每项均有对应 emoji，包含吃饭 🍚、摸鱼 🐟、刷手机 📱 等。可随时修改配置，正在计时及历史记录保留开始时的名称、图标，修改用于下一次活动。
- 记录详情支持分类筛选（分段控件，带分类图标），日期选择与“查看未完成记录”同排，空日期显示分类图标与提示；休眠、重启等中断后需核对。旧记录归入“带薪拉屎”，活动数据升级为 v3，兼容读取 v1/v2；`migrationBackup` 保留升级前的原始记录字符串，既有 `legacyBackup` 继续保留。旧版本不支持自定义活动格式，回退前需导出备份并恢复对应旧记录，新增活动不会写入旧格式。

#### 狗牛币兑换

- 设置 → 职称顶部新增“狗牛币”小卡片，显示余额与可兑换数量；点开后可将“偷来的钱”（¥1 = 1 币）和“老板欠的钱”（¥1 = 5 币）兑换成狗牛币，伴随金币飞入存钱罐、余额滚动和 ×5 盖章动画；系统开启“减少动态效果”时只显示结果。
- 只兑换今天以前已结束日子的金额，今天的金额次日可换；每天每个来源记录已兑换金额，同一笔钱不能重复兑换，不足 ¥1 的零头留到下次。之后金额被调低不会扣回已发的币，被调高只补差额。仅能兑换职称功能启用后记录的金额。
- 新增两张用狗牛币解锁的动态壁纸：“摸鱼印钞厂”（500 币，夜班工厂里印钞机吐钞、传送带送进存钱罐）和“老板欠条墙”（1000 币，软木板钉满欠条、印章盖下“已记账”、小牛举牌踱步），以分层 CSS 插画绘制，浅色与暗黑主题各有配色。设置 → 外观 → 背景中显示为上锁预览与价格；余额足够时点击两次确认购买，锁面碎裂后自动换上；余额不足时显示差额并打开兑换弹窗。购买为一次性，价格由应用内统一定义。
- 钱包单独保存在本机（`dogcow.coins.v1`），数据损坏时锁定并保留原数据。钱包随导出备份一起保存；导入不含钱包的旧备份时保留当前钱包，避免同一笔钱重复兑换。
- 修复：钱包键未加入本机存储允许列表，导致开发版兑换时提示“存储键不允许”。

## 隐私说明

以下说明依据当前仓库源码中的存储、网络与权限实现。

- **数据留在本机**：任务、薪资、考勤和设置保存在本机文件中；当前未提供账号系统或云同步，未接入使用行为统计或广告追踪。
- **联网用途明确**：中国调休日历会从 GitHub / jsDelivr 获取对应年份的公共日历，请求不附带你的任务、薪资或考勤数据。点击发布页或政策来源链接时，会交由系统浏览器打开，对方网站会接收到正常访问请求。
- **更新检查与下载**：正式版启动后会检查 GitHub Releases，并定期检查新版本；发现适配安装包时自动下载，安装前校验大小与 SHA-256。请求不附带任务、薪资或考勤数据，安装仍由你手动完成。
- **备份由你保管**：导出和迁移在本机进行，不会自动上传。数据和备份采用 JSON 格式，未做应用层加密，请勿将包含个人信息的文件公开分享。
- **界面权限隔离**：桌面界面启用上下文隔离与沙箱，关闭 Node.js 直接访问，通过受控接口读写业务数据。
- **卸载与删除分开**：删除应用不会自动清除本机数据。Mac 正式版数据位于 `~/Library/Application Support/DogCow/`，开发版位于 `~/Library/Application Support/DogCow-dev/`；需要清除时，请先退出应用并确认备份，再删除对应目录及自行导出的备份文件。
- **反馈前先脱敏**：提交截图或日志前，请隐藏薪资、任务内容和个人路径；无需提供完整个人数据文件。

## 常见问题

<details>
<summary><strong>下载链接打不开，或者下载失败怎么办？</strong></summary>

可以从 [Releases 页面](https://github.com/koxinyu11/Dog-cow/releases) 展开对应版本的 Assets，选择 `DogCow-arm64-3.1.0.dmg` 或 `DogCow-darwin-arm64-3.1.0.zip`。下载中断时请重新下载并完整解压，仍有问题可在 Issues 反馈。

</details>

<details>
<summary><strong>为什么电脑上出现多个“狗牛”图标？哪些可以清理？</strong></summary>

macOS 可能同时识别“应用程序”中的正式版、挂载安装镜像中的应用、源码目录 `build/` 和 `out/` 内的打包产物，以及 `~/Library/Application Support/DogCow-app-backups/` 内的旧应用备份。它们名称和图标相同，多个图标不代表同时运行了多个实例。

- 日常使用保留 `/Applications/狗牛.app`，从“应用程序”启动；版本可在设置中核对。
- 完成安装后推出“狗牛”磁盘镜像；不再需要的旧 DMG、ZIP、旧构建和旧应用备份可移到废纸篓。先核对路径、版本，并确认该副本没有运行；迁移尚未核对完成时保留旧版备份。
- 开发时保留源码与依赖，通过 `npm run dev` 启动；旧打包产物并不是开发实例所必需的文件。
- 清理应用副本时，不要删除 `DogCow/`、`DogCow-dev/` 业务数据目录或个人导出的数据备份。正式包实例不要为清理或开发验收而强制退出。

</details>

<details>
<summary><strong>Mac 提示无法验证开发者、应用已损坏或无法打开？</strong></summary>

先确认文件来自本仓库，并重新下载、完整解压。“无法验证开发者”时，可查看“系统设置 → 隐私与安全性”是否提供允许打开选项。若仍无法打开，请反馈 Mac 芯片、macOS 版本和完整提示，不需要关闭系统整体安全保护。

</details>

<details>
<summary><strong>支持 Windows 和 Intel Mac 吗？</strong></summary>

当前 v3.1.0 只提供 Apple Silicon（M 系列芯片）的 Mac 安装包。Intel Mac 与 Windows 安装包暂未发布，请勿下载 arm64 包用于这些设备。

</details>

<details>
<summary><strong>旧版怎么升级到 3.0？</strong></summary>

先在旧版导出备份，再下载安装 v3.1.0，通过“设置 → 迁移备份”导入并核对结果。新旧版本数据不会自动互通；确认迁移成功前，保留旧应用和原数据。本版支持用户点击“安装并重启”安装后续更新；不会在后台静默替换正在运行的应用。

</details>

<details>
<summary><strong>新版首页没有收入、工时和打卡卡片，在哪里打开？</strong></summary>

v3.0.2 默认展示九类卡片；“热量爆表”等附加卡片可从模块库加入。隐藏或移除卡片不会清除对应数据。

</details>

<details>
<summary><strong>收入金额和工资条不一样，“偷出金额”会额外加到工资里吗？</strong></summary>

收入根据你填写的薪资、排班、午休和请假等设置估算，税费参数也可能与实际工资条不同，请先核对设置。“偷出金额”只是固定收入中对应时间的价值，不会额外增加工资；最终收入以实际工资条为准。

</details>

<details>
<summary><strong>数据保存在哪里？更新后会自动同步吗？</strong></summary>

v3.0.2 的任务与设置自动保存在本机，支持备份和导入。旧版、浏览器预览与新版的数据不会自动互通，换设备或切换大版本前请先备份，再按[迁移步骤](docs/REFERENCE.md#数据与迁移)操作。若提示未保存，请先重试保存，再退出应用。

</details>

<summary><strong>遇到问题，反馈什么信息？</strong></summary>

在 [Issues](https://github.com/koxinyu11/Dog-cow/issues) 提供应用版本、系统版本、芯片型号、操作步骤和完整错误提示。截图或日志分享前，请遮住个人任务、薪资等隐私信息。

</details>
