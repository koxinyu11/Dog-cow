# 狗牛

狗牛把任务管理和工作时间计价放在一个可定制首页里。桌面版使用 **Electron + React + TypeScript + Vite**；经过回归验证的收入算法继续复用，界面和桌面接口用 TypeScript 组织。

## 功能

- 单项任务、一次性每周批量分配、标签/颜色、优先级、备注、可选时段和截止日。
- 任务进度到 100%：牛到草地终点、吃草/咀嚼与“吃完啦”；同一安排日任务全部完成撒花。完成按钮和进度滑块均支持，遵循系统“减少动态效果”。
- 周导航、42 格月历、今日概览、周统计；安排日/截止日统计去重，顺延保留截止日。
- 9 个首页模块可选、排序、恢复默认，允许全部隐藏；标题等文字可直接修改。
- 月薪、工作日和上下班设置；本月调休日历、每秒收入、今日/本月累计、实际工时与下班倒计时。
- 标准午休是否计入工时可选；带薪/无薪、整天/部分请假，支持已有记录自动保存。
- 上班/午休/继续/下班；忘记点击可补实际时间，事实来源和首次记录时间保留。
- 偷时间模式与上下班模式；迟到/午休/早退互斥拆分，补卡后重算，不额外加到工资。
- 税前/税后月薪、杭州个人险金/公积金与累计预扣税估算，允许自定义基数、比例、固定金额及其他扣项。
- 本机自动保存、明确的未保存状态、重试、迁移预览/备份/导入；横条模式、展开、单实例与窗口位置恢复。

默认首页显示任务相关的 5 个模块。进入“设置 → 首页模块”开启收入、工时、打卡、偷出金额。开关显示只影响布局，不改变计费模式或事实。

## 开发与运行

建议 Node 24、npm。依赖精确锁定在 `package-lock.json`。

```sh
npm ci
npm run dev
```

开发服务器固定为 `127.0.0.1:5180`，端口占用会明确失败；不会自动终止已有服务。若正在运行旧 Python 预览，请先退出它再运行 Vite。

```sh
npm start                 # 构建并打开 Electron，无需 Python
npm run typecheck         # renderer/main/preload 严格类型检查
npm test                  # 原有业务、迁移、草稿竞态和新持久化测试
python3 tests/auto_sync_test.py
npm run make:mac          # 当前 Mac 架构的 ZIP + DMG
npm run make:mac:x64      # Intel Mac 构建，真实运行需 Intel 环境单独验证
npm run make:win          # 在 Windows 构建 x64 安装器
```

某些 npm 环境默认禁止安装脚本；若提示 Electron 未正确安装，运行官方包内的安装器 `node node_modules/electron/install.js` 后重试。不需要改动系统安全设置。

Mac DMG 使用系统 `hdiutil`，提供应用和 `/Applications` 链接；打包后先做 ad-hoc 签名并严格验证，再生成 ZIP/DMG，挂载镜像再次核验。ad-hoc 是本地测试签名，不代表 Developer ID 签名、公证或已启用自动更新。

目标系统：macOS 13+，Apple Silicon/Intel 分别打包；Windows 10/11 x64 保留适配和构建配置。本轮按用户要求不做 Windows 构建/安装/运行验收，不能据此宣称其实机已验证。

## 数据与迁移

正式版在系统应用数据目录的 `DogCow/data/snapshot.json` 保存本机数据，开发使用 `DogCow-dev`，测试使用隔离目录。React 不直接写业务 localStorage；main 统一管理保存队列、修订号、考勤事实与收入时钟。普通秒级刷新不累加金额，也不每秒保存。

**旧 WKWebView、浏览器预览、新 Electron 的存储彼此不相通。** 原始旧数据不会自动删除或被当作空白导入。

1. 在原来使用的旧版、原路径/原浏览器端口，打开“设置 → 首页模块 → 旧版数据迁移”，导出迁移包。
2. 新版打开“设置 → 迁移与备份 → 选择迁移包”。核对预览数量后确认；已有数据先备份再替换，不自动合并。
3. 导入经过格式、SHA-256 摘要和业务校验，完成前保留 pending 状态；失败不冒充成功。旧收入 v1–v4、原始事实和兼容备份保留，损坏高版本不会降级读旧版本。
4. 新版可导出兼容备份包。过渡旧版可选择它恢复；多键恢复先写 journal，中断后暂停普通保存，允许继续或恢复原键值。

迁移文件上限 20 MiB；含个人薪资、任务和考勤，请自行妥善保存。导出不会上传个人数据。真实旧环境数据搬运需要用户在应用内触发，测试不读取用户工资或任务。

过渡旧壳仍在 `app/`、`native/`：`npm run legacy:preview` 启动浏览器旧入口，`./scripts/build-legacy.sh` 构建带导出/恢复入口的旧 Mac 壳。**不要先移动原旧 App，再假设能读取原 file origin。** 新版构建在 `out/`，不覆盖旧 `build/狗牛.app`。

## 业务口径

- 本月税后月薪除以计划标准秒数；请假不改变分母，无薪仅扣标准时段交集。
- 偷出金额是固定标准收入中的时间价值拆分，不是额外收入。隐藏卡片、缩成横条或睡眠后恢复不重置计算。
- 使用设备本地时区；目前仅支持同日班次/请假。当前设置修改后按当前口径重算整月，没有历史工资/排班版本。
- 历史无事实日期仍属于估算，不伪造成打卡。未结束日期最多计算至该日本地午夜，提示核对。
- 杭州政策是带来源与适用期的参数快照，不含单位成本、奖金、补差和年度汇算；工资条不同可自定义。计税月份保持用户设置，可点击“使用当前月”。
- 调休日历沿用 `NateScarlet/holiday-cn`，双网络来源、24 小时缓存与内置 2026 快照；不可用时明确暂停中国调休计价，不偷偷改每周模式。MIT 声明保留在 `app/income/data/holidays/`。

## 更新与发布

“检查更新”入口保留。开发/未配置的构建明确提供官方下载页，不显示假的“已是最新版”。正式签名、独立 Electron feed 与签名包升级链路验证完成前，不启用自动安装。旧 Sparkle XML 只属于旧壳，不直接供 Electron 使用。

普通 CI 只测试并上传构建产物；Windows 任务可手动选择。发布准备工作流也只生成候选产物。不会因 push main 或 v3 标签自动创建公开 Release 或改写旧 appcast。详见 [发布边界](docs/RELEASES.md)。

`scripts/auto-sync.sh` 是单独的维护者工具，不属于应用运行时；不会自动安装或运行。它包含已有的分支/上游/推送保护，测试只使用临时仓库。
